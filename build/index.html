W-PHEX

API 662 / 667 / 810을 정리합니다. 설계 조건의 본문은 welded plate heat exchanger입니다. 개스킷·세미용접 P&F는 Scope 표와 662-1→667 탭(코드 개정 노트)에서만 다룹니다. 원문 검색·챗봇은 없습니다. 항목 옆 § 원을 누르면 해당 문장이 어느 표준 조항에 있는지가 나옵니다.

현행 용접 plate-block은 API 810. 662의 fully welded pack in frame은 구판 조항이고, 667은 용접형을 명시 제외해 설계 조항이 없습니다.

한눈에 — 용접형만

2002 · 통합 구판

API 662

2nd Ed., April 2002. ISO 15547:2000과 동일.

용접형으로는 fully welded plate pack을 프레임에 구속한 형식만 정의합니다. Plate-block(column + removable panel)은 이름이 없습니다.

판 용접 NDE·sour·H2·HTHS 전용 장이 거의 없습니다. 신규 용접형 발주용 현행 코드가 아닙니다.

2022 · 용접형 제외

API 667

1st Ed., March 2022. 구 API 662-1. Plate-and-Frame.

용접형 설계 조건이 없습니다. Fully welded P&F, plate-block, plate-in-shell, brazed를 명시 제외합니다.

이 사이트에서 667 숫자는 “용접형에 적용되지 않음”을 확인하는 용도입니다.

2025 · plate-block 현행

API 810

1st Ed., October 2025 / Errata 1 July 2026. Welded Plate-block Heat Exchangers.

용접 pack + 볼트 removable panel + fixed heads + columns. Compabloc / K°Bloc / LHEBloc류.

원통 shell 안 block, panel로 공정측을 기계 세정할 수 없는 구조는 제외. HTHS는 Section 12 + API 941.

용접 plate HEX — 코드가 나누는 세 기기

“용접형 판형”이라고 한 장에 묶으면 압력경계가 섞입니다. 코드는 아래 셋을 다른 물건으로 봅니다.

662 · 667은 제외

Fully welded pack in frame

판 사이는 전부 용접. 그 pack을 P&F 프레임(cover + tie bolt)으로 구속. 662가 유일하게 이름으로 받은 용접형. 667은 명시 제외. 전용 현행 API 없음.

810

Welded plate-block

판 사이는 용접. 압력 골조는 4 column + 2 head + 4 removable panel. 유체–유체는 pack 용접, 유체–대기는 panel gasket 4장. 패널을 열어 채널을 기계 세정.

세 코드 제외

Plate-and-shell / shell 안 block

용접 pack을 원통 shell에 넣거나, panel로 전 공정측 기계 세정이 안 되는 구조. 810이 명시 제외. 압력코드 + 구매 사양으로 메움.

API 662-1 → API 667 — P&F 개정 노트

API 667 1st Ed. (March 2022)의 전신은 API 662-1 1st Ed. (February 2006, February 2011 재확인)입니다. 분량이 약 26쪽에서 45쪽(11장 + Annex A–C)으로 늘었습니다. CRE SCHTE / ISO TC 67 SC 6 계열입니다. 학습용 재구성이며 발표자료·원문 복제가 아닙니다. 발주 전 667 원문을 확인하십시오.

이 탭만 gasketed / semi-welded P&F 조항을 풉니다. 667은 fully welded P&F와 plate-block을 명시 제외합니다. 그 설계는 다른 탭입니다.

유지된 것 · 667에 없는 것

  • 유지: 차압 설계 금지, 판 최소 0.5 mm, 판 CA=0, cover+tie bolt, % fouling margin, 포트 이중 개스킷 문법.
  • 없음: Hydrogen / HTHS / API 941. 그 서비스의 P&F는 개스킷이 먼저 한계입니다.
  • 없음: fully welded P&F·plate-block 설계. 667을 걸 수 없습니다. Block은 810.

사양에 쓸 때

  • 개스킷·세미용접 P&F → API 667 + 압력코드. 662-1은 예비품 호환일 때만.
  • Datasheet: 입자 크기, fouling margin, cyclic 여부(위 정의), sour, 개스킷 재질 또는 벤더 추천 승인, 수압 전 도장, 불활성가스 충진.
  • 세미용접이면 레이저 pair, 수리 WPS 사전 검토, 동시 수압, (필요 시) 공압 대체를 찍을 것.
  • 노즐하중은 662-1 표를 그대로 넣지 말고 667 배율·방향을 따릅니다.

용접형 설계 조건 — 세 코드를 칸마다

API 810 — 설계에서 가장 중요한 것

810은 판형처럼 보여도 설계 문법은 작은 압력용기입니다. 667에는 대응 조항이 없고, 662 fully welded in frame에도 이 밀도는 없습니다. 아래를 놓치면 형식·재료·배관하중·H2가 한 번에 엇갈립니다.

1. 차압으로 설계하지 않는다. 한쪽 설계압 + 반대쪽 대기(또는 지정 진공). 운전 중 항상 차압만 걸린다고 가정하면 안 됩니다. 정지·밸브 오조작·블라인드에서 전압이 한쪽만 걸립니다.

2. 공유 부품 온도는 더 가혹한 쪽. Panel, column, 외부 볼트처럼 양측에 영향받는 부품의 설계온도는 hot/cold 중 가혹한 값입니다. 볼트 재질·크리프·개스킷이 여기서 갈립니다.

3. 전열판은 0.8 mm, 부식여유 없음. Press 전 공칭 최소 0.8 mm. CA를 판에 더하지 않습니다. 얇은 판의 건전성은 재질 선정(부식률 ≈ 무시)으로 지킵니다. Annex는 통상 0.8–1.2 mm 공급을 말합니다. 662 용접 pack의 0.5 mm보다 올렸습니다.

4. Pack 용접은 검사·수리가 가능해야 한다. 모든 plate pack 용접은 접근 가능해야 합니다. Channel을 막아버리는 수리는 사전 승인입니다. 나중에 못 고치는 코어를 사면 810 취지에 어긋납니다.

5. Panel은 압력 + 노즐하중 + 볼트하중. 스티프너로 압력을 받게 하지 않습니다(승인 예외). Panel은 head·column과 interlock되고 볼트로만 붙습니다. 볼트 ≥19 mm, 피치는 ASME VIII-2, washer는 PCC-1. 코너 대각 피치도 포함합니다.

6. 배플은 청정 허용 ΔP의 2배. Baffle은 cage에 일체, panel과 pack에 밀봉. 막힘·세정 후 차압이 커져도 배플이 먼저 꺾이면 바이패스로 성능이 무너집니다.

7. Liner는 부식 보호이지 sour 면제가 아니다. Column/head/panel/nozzle liner 최소 max(1 mm, 판두께). 개스킷 접촉폭 ≥9 mm. Panel liner는 개스킷 외주까지, plug weld. Loose liner 뒤 탄소강에도 sour 요구를 적용할지 구매자가 찍습니다. Annex는 보통 적용하라고 합니다.

8. 노즐은 set-in + 전용입 쪽으로. Flange를 panel에 용접. Studded는 합의. Slip-on 또는 fillet/부분용입 set-in은 고압·고온·H2·sour·cyclic·진공·저온·Cl.150 초과·PWHT에서 금지. 노즐 하중은 panel 교점에서 축력 양방향.

9. 기계 세정 스트림을 Scope에 묶는다. 구매자가 어느 쪽을 기계 세정할지 지정. 지정되면 판 패턴이 hydro-blast에 맞아야 합니다. Panel로 못 여는 쪽이면 810 적용 대상이 아닐 수 있습니다. 그때는 plate-and-shell 등 다른 용접형 + 압력코드입니다.

10. HTHS는 설계온도와 재료온도를 분리한다. H2 분압 >350 kPa abs이고 T>204 °C면 Section 12. 재료는 API 941 + IOW 마진. 직렬 block은 설계온도·공칭 재질을 함부로 다르게 하지 않음. 전용입 맞대기 100% 체적검사, CS는 제작 후 PWHT, 이종금속용접 금지, PMI, 습윤측 WFMT. 판 pack/liner 용접은 hardness·baseline UT에서 제외되는 주석이 있으므로 구매자가 별도 합의해야 합니다.

11. 개스킷 조인트에 단기인장 허용응력을 쓰지 않는다. 약간의 영구변형이 누설을 만듭니다. 810은 gasketed panel에 그 응력값을 금지합니다. 이 개스킷은 판 사이가 아니라 덮개 밀봉입니다.

12. Fouling은 % margin + 벽면전단. S&T fouling resistance를 넣지 않습니다. 양측 15%면 overall 25% 권고. Dirty process는 25%/50 Pa.

1. 같은 “판 사이 용접”이 다른 압력경계

둘 다 유체와 유체 사이는 용접입니다. 662 fully welded in frame은 그 용접 pack을 타이볼트가 누르는 cover 사이에 둡니다. 810은 pack을 column·head가 잡고, 네 면을 panel이 볼트로 닫습니다. 실패 모드가 다릅니다. 662 쪽은 cover 조인트·타이볼트 이완·pack이 프레임에서 떠는 움직임. 810 쪽은 채널 용접 균열, liner 뒤 포켓, comb 틈새부식, panel gasket 누설, 노즐이 panel을 비틀는 변형입니다.

2. 662가 용접 pack에 주지 못한 것

  • 판 최소 두께가 0.5 mm로 개스킷 판과 같았습니다. 810은 0.8 mm로 올립니다.
  • 판 용접을 압력코드 자격·필수 NDE로 올리지 않았습니다.
  • Column liner, comb, panel gasket 구속, 배플 2×ΔP가 없습니다. 기기가 그 부품을 쓰더라도 코드 언어가 없습니다.
  • Hydrogen / HTHS / sour 전용 장이 없습니다. 고온 수소 배관망에 넣으라는 문법이 아닙니다.
  • 노즐 하중을 “panel이라는 압력벽” 기준으로 보지 않습니다. Cover 표입니다.
  • 기계 세정을 Scope 조건으로 걸지 않습니다. 열어도 판이 안 빠지는 pack을 그대로 허용합니다.

3. 667의 공백이 실무에서 하는 일

2022년 이후 fully welded in frame이나 Compabloc류를 667에 걸면 Scope 위반입니다. 그 공백 동안 프로젝트는 압력코드 + 벤더 IOM + 구 662 문장 + 발주처 DEP를 섞어 썼습니다. 810은 그 섞음을 plate-block에 한해 코드로 회수합니다. Fully welded in frame과 plate-and-shell은 여전히 공백입니다.

4. 누설을 어디에 두는가 (용접형끼리)

용접형은 교차오염을 1차로 용접으로 끊습니다. 남은 외부 누설점은 662 프레임 조인트이거나 810 panel gasket입니다. 둘 다 “판 사이 탄성 개스킷 분출”이 아닙니다. Interstream leak test(He)는 810이 기본값을 줍니다. 662는 지정 시입니다.

5. 정비

두 용접형 모두 전열판을 한 장 빼지 못합니다. 662 프레임형은 cover를 열어 pack 외면을 보고, 810은 panel을 열어 채널을 봅니다. 면적이 부족하면 판을 끼우는 것이 아니라 병렬 block이거나 기기 교체입니다.

6. 수소·고온

662 용접 pack을 HTHS에 넣는 코드 경로가 없습니다. 810은 API 941을 normative로 걸고 설계온도와 재료선정 온도를 분리하며, 전용입·PWHT·DMW 금지·PMI를 강제합니다. 즉 810 plate-block은 “판형”이 아니라 수소 배관망에 들어가는 소형 용접용기로 쓰라고 쓰여 있습니다.

한 줄로

662 용접형은 프레임에 가둔 용접 cassette이고, 810은 용접해 두고 panel로 닦는 소형 용기입니다. 667은 둘 다 설계하지 않습니다.

제품 지도 — 같은 810 문법, 다른 용접 학교

Compabloc / K°Bloc / GEABloc / LHEBloc은 모두 용접 plate pack + 4면 removable panel입니다. API 810이 이 형식을 코드로 받았습니다. 판 패턴·column liner·용접 방법은 벤더가 다릅니다. 카탈로그 압력·온도는 모델·연도 값이며 코드 한도가 아닙니다.

Fouling은 % margin + 벽면전단

컴팩트 HEX의 U가 높을수록 같은 S&T fouling resistance가 % 과잉면적을 비정상적으로 키웁니다. Kelvion 예시: Uclean 2000인 S&T에 Rf 0.0001 m²K/W → 약 20% margin. Uclean 6000인 bloc에 같은 Rf → 약 60% margin. 유속이 떨어져 오히려 때립니다. 662 Annex와 810 Annex가 같은 이유로 % margin + shear를 씁니다.

  • 양쪽이 모두 15%를 넘으면 overall 25% (810 권고). margin은 Uclean에 걸고 면적에 이중으로 걸지 않습니다.
  • 허용 ΔP는 청정 기준. 펌프·배관 수력은 fouled ΔP.
  • K°Bloc HTRI CTW 사례: 0.45 m/s에서도 벽면전단 ~60 Pa, S&T 1.8 m/s ~15 Pa. 유속만 비교하지 마십시오.
  • 왁싱은 margin 표 밖. 발주처와 별도 합의. Kelvion은 정지하 원유를 단기로만 허용합니다.
  • 발주처 DEP가 용접 판형 % 표를 주면 그 표가 우선입니다. P&F 전용 DEP 숫자(개스킷 판 0.6 mm, 타이볼트)는 plate-block에 복사하지 마십시오.

열계산에서 자주 엇갈리는 것 (plate-block)

  • Bloc은 패스 단위 교차류입니다. HTRI/벤더 프로그램 없이 S&T F-factor만 넣으면 approach를 과대평가합니다.
  • NTU가 큰 회수는 향류 패스를 쌓습니다. 출구온도가 안 정해지면 NTU-ε, 정해지면 LMTD.
  • High θ (chevron) = 높은 U, 높은 ΔP, jetting에 유리. Low θ (dimple/wide) = 반대. 한 기기 안에서 thermal length를 맞춥니다.
  • 810 dimple 5 mm 갭은 고체용이지 고θ가 아닙니다.

설치·운전·세정 — 용접 plate-block IOM

코드는 기기를 맞게 사고, IOM은 기기를 안 깨게 돌립니다. Compabloc 영문 IOM, Kelvion K°Bloc 운전지침, Pertamina Balikpapan RDMP(IKAN) 개정에서 뽑았습니다.

배치

  • Panel 4면을 열 공간을 outline에 넣습니다. 밸브는 패널을 막지 않는 spool 뒤. 810 Scope(기계 세정)와 정면 충돌하는 지점입니다.
  • 패널 전용 인양 러그로 본체를 들지 않습니다. Compabloc IOM이 명시합니다.
  • 패널 볼트 토크는 단열 전에, 그리고 수송·장기 보관 후에 다시. 2–3개월 정지 후 재기동 전에도.
  • 컴팩트하다고 노즐을 짧게 쓰면 볼트를 못 뺍니다. 단열 너머 through-bolting 제거가 필요합니다.

  • 화학 후 철저히 수세·배수. 기계 세정은 패널을 열고 hydro-blast / cleaning bar를 약 45°로.

  • 원유 정체: Kelvion은 수시간 단기는 왁스·부식 모두 크게 보지 않음. 중장기 정지는 세정·플러시·배수.
  • 수압 후 또는 현장에서 panel을 다시 닫으면 개스킷을 갈고 100–170 kPa soap 공압 (810).

  • 국내 평가(P2-4PE, 2011): 용접 plate HEX 제작사가 적고, 본 제작·문서는 해외, 국내법만 로컬.
  • 도면만 있는 패키지(DHP RPLC 등)는 운전 규칙을 주지 않습니다. IOM이 계약 문서인지 확인하십시오.

알아두면 좋은 것들 — 용접형만

사양·발주

  • 장비 스케치를 보고 코드를 겁니다. Plate-block에 667을 걸거나, fully welded in frame에 810을 걸면 Scope 위반입니다.
  • 662:2002 용접 pack 조항은 레거시입니다. 신규 plate-block은 810. Fully welded in frame·plate-and-shell은 압력코드 + 구매 사양으로 메우고, 810의 용접/NDE를 선택 인용할지 명시하십시오.
  • API는 압력용기 코드가 아닙니다. ASME VIII / EN 13445를 따로 지정하고, API는 그 위의 supplemental입니다.
  • 810 직렬 unit은 블록마다 설계온도·재질을 다르게 쓰지 않는 것이 기본입니다. 핫엔드만 Cr-Mo면 구매자가 명시해야 합니다.

열설계·운전

  • S&T fouling factor를 그대로 넣으면 과설계·저유속이 됩니다. % margin과 wall shear를 쓰십시오.
  • Chevron 각 정의가 vendor마다 다릅니다. 810은 “흐름 수직선 기준”입니다. HTRI/제작사 각도와 혼동하지 마십시오.
  • 입자 크기가 gap의 50%를 넘으면 strainer가 필요합니다 (662 Annex 취지, 810도 같음).

재료·손상기구

  • Loose liner는 sour 면제 티켓이 아닙니다. 810 Annex는 모재에도 sour 요구를 적용하라고 합니다.
  • HTHS에서 설계온도 ≠ 재료선정 온도일 수 있습니다. 금속 온도가 유체 설계온도보다 낮다고 주장하려면 계측·IOW가 필요합니다.
  • 810은 주강을 원칙 금지합니다. 노즐·head에 주조품이 들어오면 막으십시오.
  • 판이 얇아서 부식여유를 못 줍니다. 재질을 한 단계 올리는 것이 CA 3 mm보다 맞습니다. LHE 예: 50 °C에서 합금에 따라 Cl⁻ 수십~수천 ppm, Ti 해수는 ~130 °C — 카탈로그이지 코드가 아닙니다.

제작·검사에서 자주 빠지는 것

  • 810에서 수압 후 panel을 다시 열면 개스킷을 갈고 100–170 kPa soap 공압이 필수입니다. 현장 설치 후 재조립에도 해당될 수 있습니다.
  • 시험수 Cl⁻는 662가 30 ppm, 810은 50 ppm입니다. 구 사양을 그대로 복사하면 불일치입니다.
  • 수소 서비스에서 liner가 만든 밀폐 공간은 벤트가 필요합니다. 빼면 운전 중 압력 축적·균열 위험이 있습니다.
  • pack/liner 용접이 HTHS hardness·baseline UT에서 제외되는 주석이 있으면, 그 시임을 어떻게 볼지 구매자가 별도 합의해야 합니다.

배관·배치

  • 810은 panel 제거 공간을 outline에 넣습니다. 단열·플랫폼이 그 공간을 먹으면 기계 세정이 불가능해 Scope와 충돌합니다.
  • 노즐 하중을 S&T처럼 때리면 panel 변형·개스킷 누설로 갑니다. 플랜지 등급을 배관하중 때문에 한 단계 올리는 것이 810 문법입니다.

구조 — welded plate-block을 분해해서 보기

부품 이름은 벤더마다 다릅니다. 같은 물건을 Alfa는 girder, Kelvion은 column, 도면 불어는 longeron이라고 부릅니다. 유체와 유체 사이는 판 용접, 유체와 대기 사이는 panel gasket 네 장입니다.

밖에서 안 이름표 두 회로 전열판 Pack 용접 Column / girder Comb / liner / wing Head Panel Baffle 노즐·벤트 하중 경로 열었을 때

이 기계가 한 문장으로 뭔가

정사각형(또는 직사각형) 전열판을 수백 장 겹쳐, 한 장은 가로 두 변, 다음 장은 세로 두 변을 용접합니다. 그러면 판 사이에 서로 통하지 않는 두 개의 챔버가 생깁니다. 그 용접 다발을 네 모서리 column과 위·아래 head로 감싸고, 네 면에 노즐 달린 panel을 볼트로 닫습니다. 판과 판 사이에는 개스킷이 없습니다. 개스킷은 panel 둘레에만 있습니다.

Fully welded pack in frame(662)은 같은 용접 다발을 타이볼트 프레임에 가둡니다. 이 형식(810)은 column·head가 pack을 잡고, 볼트는 용기 덮개(panel)만 조입니다.

밖에서 안으로 — 분해 순서

  1. Support / foot. 바닥 네 귀. 수평 기기면 별도의 saddle. 인양은 head 러그. Panel 러그는 panel만.
  2. Four panels. 탄소강 덮개. 노즐, 벤트/드레인, 이름판이 여기 붙습니다. 안쪽은 도장 또는 합금 liner.
  3. Four panel gaskets. 기기 전체에서 공정 개스킷은 사실상 이 네 장입니다.
  4. Baffle cage. 열린 면에서 보이는 가로막. 패스 수를 만듭니다. 빼도 pack은 남습니다.
  5. Plate pack. 전열의 전부. 열 수 없습니다. 채널이 네 면으로 열려 있습니다.
  6. Comb / column liner / girder lining. Pack 모서리를 column에 밀봉·지지하는 합금 이음. “접힌 날개”는 Alfa IOM이 아니라 상대사 비교 그림입니다.
  7. Four columns (girders). 수직 네 기둥. 볼트 하중과 압력을 받습니다.
  8. Top and bottom heads. 위·아래 두꺼운 판. End plate 및 (Alfa) PTFE sheet와 만납니다.

좌표계 — 네 면, 두 유체, Aa·Ab·Ba·Bb

Pack을 큐브로 보면 네 옆면이 모두 열려 있습니다. 용접이 면을 번갈아 막기 때문입니다. Compabloc 블록 조립도에서는 채널을 Aa / Ab / Ba / Bb로 표시합니다.

  • 첫 글자 A 또는 B = 어느 공정측 유체인가. 인접 채널은 반드시 다른 유체입니다.
  • 둘째 글자 a 또는 b = 그 유체가 나가는 두 반대면. A는 앞·뒤, B는 좌·우처럼 직교합니다.
  • 한 패스 안에서 A는 B의 채널을 가로질러 흐릅니다 (교차류). 배플이 면을 가로막으면 유체가 위 또는 아래로 다음 패스에 들어가, 기기 전체는 향류에 가까워집니다.
  • 그래서 노즐은 “A 입구 panel 아래, A 출구 panel 위”처럼 같은 회로의 반대면·반대 높이에 붙는 경우가 많습니다. 다패스면 입·출구가 같은 panel에 오기도 합니다.

코너 용접(도면의 weld b, 판팩 용접 a / a')이 두 회로가 모서리에서 섞이지 않게 막습니다. 여기가 새면 교차오염입니다. Panel gasket이 새면 외부 누설입니다. 실패 모드가 다릅니다.

전열판 한 장

한 장은 정사각에 가깝고, 프레스로 골을 넣습니다. 810 최소 공칭 두께는 press 전 0.8 mm. 부식여유는 판에 더하지 않습니다. Kelvion 카탈로그 예: BT20–50은 0.8 mm, BT75는 1.0 mm, BT120은 1.0–1.2 mm.

판 패턴이 “C-type”이면 Compabloc 계열 골이지, 667 개스킷 판의 C 모델이 아닙니다. 성형 후 전 판을 vacuum 또는 PT 하는 것이 810의 출발점입니다. 개스킷 홈이 없으므로 기밀은 오직 용접입니다.

Plate pack — 두 챔버를 만드는 용접

한 장 걸러 용접 방향이 90° 돕니다. 홀수 번째 판은 긴 변 두 곳을 이웃과 용접하고, 짝수 번째 판은 짧은 변 두 곳을 용접합니다. Kelvion 표현: 각 판을 두 길이방향 변과 코너에서 용접해 압력에 견디는 분리 챔버 두 개를 만든다.

  • Cassette / pair. 두 장을 먼저 용접한 뒤 카세트를 쌓는 제작도 있습니다. 그 다음 카세트 사이를 다시 용접해 두 번째 회로를 닫습니다.
  • 1차 용접 vs 2차 용접. 한쪽 회로를 닫은 뒤 pack을 압축(pre-tension)하고 반대 회로를 용접하는 학교가 있습니다. Kelvion은 이 예압이 금속 접촉을 유지해 진동·피로를 줄인다고 합니다. 레이저 맞대기만 하고 예압을 못 하면 pack이 아코디언처럼 움직인다는 것이 상대를 공격하는 논리입니다.
  • 아코디언. Compabloc IOM: 양 회로를 동시에 비우거나 극단적으로 걸면 pack이 아코디언처럼 숨 쉬며 피로합니다. 차압 설계를 금지하는 810과 같은 물리입니다. 한쪽만 설계압, 반대는 대기일 수 있습니다.
  • NDE. 판–판은 PT 또는 bubble. Pack의 모든 용접은 나중에 접근 가능해야 합니다. 채널을 플러그로 막아 버리는 수리는 사전 승인.
  • 용접 방법. 소형 Compabloc CP15/20은 TIG, 대형 CPL/CPK/CPX는 레이저. Kelvion은 판–판 자동 TIG + 예압. GEA 비교자료는 자사를 lap(여유 살 있음), 상대를 butt(여유 살 없음)로 그리기도 합니다. 사양에는 방법보다 예압·겹침 여부·NDE·접근성을 적으십시오.

Pack 자체는 압력용기의 “코어”이지 아직 완전한 외압 경계가 아닙니다. 네 면이 열려 있으므로, 그 면을 닫는 것이 panel이고, 모서리를 닫는 것이 column+comb입니다.

Column / girder — 네 모서리 기둥

Pack의 네 세로 모서리에 붙는 두꺼운 부재입니다. 겉에서 보면 기기의 네 귀퉁이입니다. Panel 볼트가 여기(그리고 head)에 들어갑니다. 타이볼트 프레임이 없는 이유입니다.

  • 역할. (1) pack을 길이 방향으로 묶는다. (2) panel 볼트 하중을 받는다. (3) 노즐이 panel에 가하는 힘·모멘트를 head와 나눠 가진다. (4) liner를 통해 공정 유체와 탄소강 골조를 가른다.
  • 재질. 골조 column/head/panel은 탄소강 도장이 흔하고, 유체에 닿는 면만 합금 liner. 전부 합금으로 깎은 기기도 있습니다. CPX50 150장 실기기 예: column·head가 SA-240 316L 통짜, column 공칭 두께 90 mm / 가공 후 79.5 mm, 길이 약 1.02 m, head 공칭 80 mm. 0.8 mm 판 옆에 80–90 mm 기둥이 서는 것이 이 형식의 스케일입니다.
  • 가공. Pack 접촉면은 평탄·직진이 생명입니다. Comb가 들어갈 홈, panel gasket이 앉는 자리, 볼트 피스가 여기 깎입니다. 810은 gasket면 평탄도·Ra·PWHT 후 최종 가공을 말합니다.
  • Alfa 분해 시 주의. Panel을 풀 때 먼저 girder 쪽 너트를 풀어 girder가 휘지 않게 합니다. Column은 “그냥 기둥”이 아니라 볼트 플랜지 역할을 겸합니다.
  • 주강. 810은 주강 원칙 금지. Kelvion/GEA는 상대 head가 주강·다공질이라고 공격합니다. 입찰 때 head/column 재질·성형 방법을 명시하십시오.

Comb, column liner, wing — 모서리를 닫는 세 학교

Pack의 판 끝은 톱니입니다. 골 마루와 골 바닥이 교차하므로, 매끈한 막대만 대면 골 따라 새는 길이방향 누설 경로가 남습니다. 그 이빨을 메우는 부품이 comb입니다. 벤더 싸움이 가장 구체적인 지점입니다.

1. Comb + column liner (Kelvion / GEABloc이 자사라고 그리는 것)

  • Comb. 판 끝 프로파일에 맞춘 두꺼운 빗. 레이저 절단으로 이빨 간극을 줄입니다. 카탈로그는 1.2–3 mm, 강조점은 3 mm 한 장.
  • Column liner. Column 안쪽을 덮는 합금 판. Comb와 liner를 서로 밀봉 용접해 틈새 포켓을 없앱니다.
  • 용접. 판–판은 자동 TIG, pack–comb/liner는 수동 TIG. 겹쳐 지나가며 두 번 녹이는 overlapping weld를 피한다고 합니다. 모든 시임이 열면 보인다고 합니다 (100% inspectability).
  • 이빨이 pack을 예압 상태에서 물면, 운전 중 판이 column에서 떠지 않습니다.

2. Wing + 얇은 liner + RSEW (GEA/Kelvion이 상대를 이렇게 그림)

  • 근거: GEABloc vs Competitor 내부메모 (2010), K°Bloc Korea KW15 (2018) “OTHERS” 칸. Alfa 로고·Compabloc IOM 문장이 아닙니다.
  • 그 슬라이드: 판 코너 edge folding → 0.8–1.2 mm wings from plates → 얇은 column liner 2장 + RSEW, overlapping weld, 틈새부식 후보.
  • Compabloc IOM이 실제로 쓰는 말은 girder lining입니다. 접는다/wing이라는 제작 단계는 없습니다.

3. LHE — 열팽창을 위한 빈 공간

  • Column lining을 각진 상자 대신 원형에 가깝게 두고, lining 뒤에 빈 공간을 둡니다. 열로 pack이 늘어날 때 용접이 찢어지지 않게 하려는 특허입니다.
  • Top/bottom lining에 파형을 넣어 column lining 용접점의 응력 집중을 줄입니다 (자사 주장 약 25%).
  • Screen lining이 움직이는 영상으로 “고정 용접만으로는 부족하다”를 보여 줍니다. 기동 승온 한도와 같은 물리입니다.

사양에 쓸 언어. “Comb를 써라”가 아니라: column liner 최소 두께(810: max(1 mm, 판 두께)), 개스킷 접촉폭 ≥9 mm, 겹침 저항용접 여부, pack 예압 후 2차 용접 여부, 열면 모든 pack 모서리 용접이 보이는지, lining 뒤 포켓을 sour/H2에서 어떻게 볼지.

810에서 loose liner는 모재의 sour 면제가 아닙니다. Comb 뒤 탄소강 column이 있으면 그 강을 wet H2S 범위에 넣을지를 구매자가 찍습니다.

Top / bottom head, end plate, PTFE sheet

  • Head. Pack의 위·아래를 덮는 두꺼운 고정 덮개. 인양 러그가 보통 여기 있습니다. 볼트가 column과 함께 사각형 틀을 만듭니다.
  • End plate. Pack의 맨 위·맨 아래 전열판 또는 그보다 두꺼운 마감 판. 공정이 위·아래로 새지 않게 합니다. 옆면 네 곳만 열리게 하는 뚜껑입니다.
  • PTFE sheet (Compabloc, 2004-10 이후). 탄소강 head와 합금 end plate 사이에 시트 두 장. 갈바닉·틈새 부식을 막고, CS와 SS가 미끄러지며 긁히는 것을 줄입니다. Head까지 합금이면 이 시트가 없을 수 있습니다.
  • 파형 lining (LHE). Head liner를 평판이 아니라 물결로 두어 column lining 용접 응력을 분산.

Head는 “열리지 않는 panel”입니다. 세정 접근은 네 옆면만. 위아래로 유체가 나가야 하면 그것은 nozzle이 아니라 옆면 패스가 위 head 근처에서 꺾이는 것입니다.

Panel — 유일한 볼트 덮개

네 장의 덮개가 네 회로 면을 닫습니다. 810의 정비 단위가 판이 아니라 panel인 이유입니다. Compabloc IOM 문장: 기기에 들어가는 개스킷은 exploded view의 panel gasket 네 장뿐이다.

  • 본판. 대개 탄소강. 노즐이 여기 용접됩니다 (set-in flange). 스티프너로 압력을 받게 하지 않는 것이 810 기본입니다.
  • Liner. 공정이 탄소강을 보면 안 될 때. Pack과 같은 합금, 개스킷 외주까지 덮고 plug weld. 최소 max(1 mm, 판 두께), 개스킷 접촉폭 ≥9 mm.
  • 안쪽 도장. Liner가 없으면 내면에도 외부와 같은 primer. 유체가 도장과 안 맞으면 lined 또는 내면 미도장.
  • Gasket. 흑연, PTFE(Gylon 등), camprofile, 아라미드/NBR. 외주가 구속되어야 분출하지 않습니다. 멀티피스는 interlock. 수압 후 패널을 다시 열면 개스킷을 갈고 100–170 kPa soap 공압 (810).
  • 볼트. ≥19 mm, TS ≥75 ksi, PCC-1 washer, 피치는 VIII-2, 코너 대각 포함. Jackscrew 또는 주위 ≥5 mm로 패널이 떨어질 틈.
  • Push-off / 나사 구멍. Kelvion은 패널에 push-off bolt용 나사 구멍을 둡니다. 개스킷에 붙은 패널을 망치로 떼지 말라는 뜻입니다.
  • 인양 러그. 패널 전용. 본체를 이 러그로 들면 IOM 위반입니다. 노즐로 들어 올리는 것도 금지.
  • 열 규칙 (K°Bloc). 동시에 마주 보는 두 면까지만. 네 면을 한꺼번에 열면 pack·baffle이 지지를 잃습니다. 패널에 위치 표시를 하고 제자리에 되돌립니다.
  • 평탄도. 변 >1 m → 0.8 mm, ≤1 m → 0.6 mm. Ra 3.2–6.3 μm. PWHT 후 최종 가공. Column/head liner 개스킷면에는 이 평탄도를 그대로 적용하지 않는다는 주석이 있습니다.

노즐 하중표의 분모가 2.5인 이유: 하중 작용점이 nozzle–panel 교점이고, panel이 얇은 덮개이기 때문입니다. 축력은 당김과 미는 방향 모두. 컴팩트하다고 S&T처럼 배관을 붙이면 panel이 먼저 굽고 gasket이 셉니다.

Baffle — 교차류를 향류로 쌓는 가로막

Panel을 열면 pack 면에 가로로 꽂힌 판이 보입니다. 그것이 baffle입니다. 없으면 그 면은 한 패스 교차류로 끝나 온도교차에 약합니다. 있으면 유체가 지그재그로 여러 번 pack을 가로지릅니다.

  • Stamped baffle. 얇게 찍어 만든 막. 각 회로에 패스 수만큼 있습니다. 실기기 예: Side A 5-pass, Side B 5-pass, SA-240 316L. 패스 수는 열설계가 정합니다. 좌우 회로의 패스 수가 다를 수 있습니다.
  • Cage / bracket / ladder. 두 세로 빔(upright)에 baffle을 스폿 용접한 사다리. Compabloc은 통째로 빼기 어려우면 한 장씩 끼우라고 합니다. 운전 후 pack이 조금 휘기 때문입니다.
  • 밀봉. Baffle 끝은 pack 골과 panel 쪽에 맞닿아야 바이패스가 없습니다. Compabloc: 각 baffle에 Vitex PTFE 개스킷, girder lining의 삼각 홈에 PTFE cord. 홈의 기름을 닦고 넣습니다. 810: baffle은 cage에 일체, panel과 pack에 밀봉, 설계 ΔP ≥ 2 × clean allowable ΔP.
  • 차압 한계. 일반 stamped baffle이 견디는 차압은 Compabloc IOM이 2–3 bar로 말합니다. 수격·고점도면 reinforced: 세로 튜브가 baffle을 받쳐 cage를 단단하게 합니다.
  • LHE. 상대 기기는 baffle이 굽고 미끄러져 U가 떨어지고 ΔP가 오른다고 하며, 추가 지지로 푼다고 합니다. 막힌 뒤 차압이 배플 설계를 넘으면 성능이 아니라 구조가 먼저 갑니다.
  • 점검. 세정만이면 baffle cage를 굳이 빼지 않습니다. Cage에 가려진 pack 용접을 보려면 뺍니다. 힘으로 빼면 pack을 찢습니다.

노즐, 벤트, 드레인, 이름판

  • 노즐은 panel에 붙습니다. Studded는 합의. Slip-on / 부분용입 set-in은 고압·고온·H2·sour·cyclic·진공·저온·Cl.150 초과·PWHT에서 금지 (810).
  • 소형 Compabloc(CP15–40): 노즐을 가능한 한 위·아래에 두어 노즐 자체가 벤트/드레인이 됩니다. 자가 배기·배수.
  • 대형(CP50–120): panel에 1" 또는 2" 플랜지 벤트/드레인을 따로 둡니다. 차단 밸브를 달고, 가스가 나오는 회수 서비스는 벤트를 상시 개방하라고 IOM이 말합니다. 연결하지 않으면 보증 제외 문구까지 있습니다.
  • 배관은 panel을 빼는 데 방해되지 않게 spool. 노즐로 기기를 들지 않음.
  • 이름판은 보통 panel. 설계 P/T, 회로 표시, PED 카테고리. 운전은 이름판이 IOM보다 우선하는 한도입니다.

Panel을 열면 보이는 것

세정 또는 용접 점검 때문에 마주 보는 한 쌍을 열었다고 가정합니다.

  1. 가장 앞: 떨어진 panel. 내면 도장 또는 liner, 노즐 보어, gasket 자리의 조흔.
  2. 테두리: column 두 개와 head 두 개가 만드는 창틀. Gasket이 앉던 가공면.
  3. 창 안 앞쪽: baffle들. 가로막이 pack 골을 가로지릅니다. PTFE 끈이 girder 삼각 홈에 남아 있을 수 있습니다.
  4. 그 뒤: 전열판의 열린 채널. Chevron이면 V골이 보이고, dimple이면 점 패턴입니다. 여기로 hydro-blast를 약 45°로 넣습니다.
  5. 창의 좌우 세로 모서리: comb 이빨 또는 wing이 판 끝과 맞물린 용접선. 810이 “접근 가능해야 한다”고 한 바로 그 선입니다.
  6. 빼지 말아야 할 것: pack 자체. 판을 한 장 꺼내는 기계가 아닙니다. 채널이 막혀 플러그를 박는 순간 그 경로는 영구 손실입니다.

반대쪽 panel은 아직 닫혀 있으므로 그 회로는 아직 압력 경계입니다. 네 면을 동시에 열면 pack은 네 column에만 물린 채 서 있고, baffle cage는 지지를 잃습니다.
