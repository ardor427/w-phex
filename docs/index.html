W-PHEX

API 662 / 667 / 810에 Compabloc·K°Bloc·LHEBloc 카탈로그, IOM, 발주처 DEP, 교육자료를 더해 welded plate HEX 실무 노트로 정리했습니다. 원문 검색·챗봇은 없습니다.

신규 용접형 plate-block은 API 810. 개스킷·세미용접 plate-and-frame은 API 667. 벤더 숫자는 카탈로그 당시 값이며 코드가 아닙니다.

용접 형식 네 가지

662 · 667

Semi-welded P&F

두 판을 pair로 용접, pair 사이는 개스킷. 한쪽만 용접 챔버. 프레임이 압력경계.

662 only

Fully welded pack in frame

개스킷을 전부 용접으로 대체한 pack을 프레임으로 구속. 667은 명시 제외. 현행 전용 API 없음.

810

Welded plate-block

판 사이는 용접, 외부는 panel gasket. Panel을 열어 기계 세정. 고온고압·H2에 맞음.

세 코드 제외

Plate-in-shell

원통 shell 안 block, 또는 panel로 전 공정측 세정이 안 되는 구조. Brazed/plate-fin도 별도 규격(구 662-2 / ISO 15547-2).

코드 계보

810 정의: welded plate-block = 용접 plate pack + panels + fixed heads + columns. Pack 자체는 전열판 + column liner + head liner의 용접 조립체입니다. 667 정의: plate-and-frame = gasketed 또는 semi-welded plate pack + supporting frame.

API 810 — 설계에서 가장 중요한 것

810은 판형처럼 보여도 설계 문법은 작은 압력용기입니다. 아래를 놓치면 형식·재료·배관하중·H2가 한 번에 엇갈립니다.

1. 차압으로 설계하지 않는다. 한쪽 설계압 + 반대쪽 대기(또는 지정 진공). 운전 중 항상 차압만 걸린다고 가정하면 안 됩니다. 정지·밸브 오조작·블라인드에서 전압이 한쪽만 걸립니다.

2. 공유 부품 온도는 더 가혹한 쪽. Panel, column, 외부 볼트처럼 양측에 영향받는 부품의 설계온도는 hot/cold 중 가혹한 값입니다. 볼트 재질·크리프·개스킷이 여기서 갈립니다.

3. 전열판은 0.8 mm, 부식여유 없음. Press 전 공칭 최소 0.8 mm. CA를 판에 더하지 않습니다. 얇은 판의 건전성은 재질 선정(부식률 ≈ 무시)으로 지킵니다. Annex는 통상 0.8–1.2 mm 공급을 말합니다.

4. Pack 용접은 검사·수리가 가능해야 한다. 모든 plate pack 용접은 접근 가능해야 합니다. Channel을 막아버리는 수리는 사전 승인입니다. 나중에 못 고치는 코어를 사면 810 취지에 어긋납니다.

5. Panel은 압력 + 노즐하중 + 볼트하중. 스티프너로 압력을 받게 하지 않습니다(승인 예외). Panel은 head·column과 interlock되고 볼트로만 붙습니다. 볼트 ≥19 mm, 피치는 ASME VIII-2, washer는 PCC-1. 코너 대각 피치도 포함합니다.

6. 배플은 청정 허용 ΔP의 2배. Baffle은 cage에 일체, panel과 pack에 밀봉. 막힘·세정 후 차압이 커져도 배플이 먼저 꺾이면 바이패스로 성능이 무너집니다.

7. Liner는 부식 보호이지 sour 면제가 아니다. Column/head/panel/nozzle liner 최소 max(1 mm, 판두께). 개스킷 접촉폭 ≥9 mm. Panel liner는 개스킷 외주까지, plug weld. Loose liner 뒤 탄소강에도 sour 요구를 적용할지 구매자가 찍습니다. Annex는 보통 적용하라고 합니다.

8. 노즐은 set-in + 전용입 쪽으로. Flange를 panel에 용접. Studded는 합의. Slip-on 또는 fillet/부분용입 set-in은 고압·고온·H2·sour·cyclic·진공·저온·Cl.150 초과·PWHT에서 금지. 노즐 하중은 panel 교점에서 축력 양방향.

9. 기계 세정 스트림을 Scope에 묶는다. 구매자가 어느 쪽을 기계 세정할지 지정. 지정되면 판 패턴이 hydro-blast에 맞아야 합니다. Panel로 못 여는 쪽이면 810 적용 대상이 아닐 수 있습니다.

10. HTHS는 설계온도와 재료온도를 분리한다. H2 분압 >350 kPa abs이고 T>204 °C면 Section 12. 재료는 API 941 + IOW 마진. 직렬 block은 설계온도·공칭 재질을 함부로 다르게 하지 않음. 전용입 맞대기 100% 체적검사, CS는 제작 후 PWHT, 이종금속용접 금지, PMI, 습윤측 WFMT. 판 pack/liner 용접은 hardness·baseline UT에서 제외되는 주석이 있으므로 구매자가 별도 합의해야 합니다.

11. 개스킷 조인트에 단기인장 허용응력을 쓰지 않는다. 약간의 영구변형이 누설을 만듭니다. 810은 gasketed panel에 그 응력값을 금지합니다.

12. Fouling은 % margin + 벽면전단. S&T fouling resistance를 넣지 않습니다. 양측 15%면 overall 25% 권고. Dirty process는 25%/50 Pa.

API 667 대비 API 810이 다른 점

조항을 나란히 놓는 것을 넘어, 두 코드가 가정하는 기기와 실패 모드가 다릅니다.

1. 압력경계의 철학

667은 압축된 판다발입니다. Tie bolt가 개스킷을 눌러 압력을 담고, 나중에 볼트를 풀어 판을 꺼냅니다. 810은 용접된 코어 + 볼트 덮개입니다. 유체 간 경계는 용접이고, panel은 용기 덮개입니다. 그래서 667의 20% 증설·개별 판 교체는 810에 없고, 810의 pack 용접 NDE·liner·HTHS는 667에 없습니다.

2. 누설을 어디에 허용하는가

667은 포트 이중 개스킷과 대기 벤트로 교차오염을 외부 누설로 드러나게 만듭니다. Spray leak가 설계 전제라 shroud·drip tray가 있습니다. 810은 유체 간을 용접으로 막아 교차오염을 1차로 끊고, 외부는 panel gasket 한 겹입니다. 실패 모드가 “개스킷 분출”에서 “채널 용접 균열 / liner 뒤 포켓 / panel 조인트 누설”로 바뀝니다. 같은 “개스킷”이라는 단어가 667에서는 공정 밀봉, 810에서는 덮개 밀봉입니다.

3. 정비 단위

667의 정비 단위는 판(또는 pair)입니다. 오염되면 열고, 빼고, 20%를 더 끼웁니다. 810의 정비 단위는 panel입니다. 유로를 열어 하이드로블라스트하지만 전열면을 재적층하지 않습니다. 면적이 부족하면 기기를 바꾸거나 병렬 block을 늘립니다. 직렬 block의 재질·설계온도를 함부로 다르게 하지 말라는 조항이 그래서 있습니다.

4. 배관하중을 누가 받나

667의 노즐은 주로 fixed cover에 붙고, 가동커버 노즐은 약합니다. 하중표도 Cl.300까지입니다. 810의 노즐은 panel이라는 압력벽에 붙습니다. Cl.600 표가 있고, 축력을 양방향으로 보며, 플랜지 압력-온도 등급을 배관하중 때문에 깎을 수 있다고 명시합니다. 컴팩트 HX라고 노즐을 S&T처럼 때리면 810에서는 panel 변형·개스킷 누설로 바로 갑니다.

5. 수소·고온은 810만 코드 언어를 갖는다

667은 정유 P&F용으로 sour까지는 가져왔지만 hydrogen/HTHS 장이 없습니다. 개스킷 수명이 그 서비스를 사실상 막습니다. 810은 API 941을 normative로 걸고, 설계온도와 재료선정 온도를 분리하며, 전용입·PWHT·DMW 금지·PMI를 강제합니다. 즉 810은 “판형”이 아니라 수소 배관망에 들어가는 소형 용접용기로 쓰라고 쓰여 있습니다.

6. 검사 가능한 것과 불가능한 것

667은 열어보면 됩니다. 판 용접 NDE는 세미용접에 한해 구매자 지정입니다. 810은 닫힌 코어를 전제로 하므로 성형 후 전 판 검사, 판용접 bubble/PT, liner PT, 접근 가능 pack 용접이 기본입니다. 열어볼 수 없는 곳을 설계에 넣으면 810을 만족시키기 어렵습니다.

7. 사양을 쓰는 단위가 다르다

667 datasheet의 핵심은 개스킷 재질·수명, 판 gap, 입자 크기, 타이볼트, 가동커버 지지입니다. 810 datasheet의 핵심은 세정 대상 스트림, liner vs overlay, panel gasket 구속, hydrogen/HTHS, baffle 밀봉, pack 용접 NDE입니다. 한 장의 구 PHE 사양에 둘을 동시에 걸면 제작자가 어느 압력경계를 따라야 하는지 모호해집니다.

한 줄로

667은 열고 닦는 판형이고, 810은 용접해 두고 panel로 닦는 소형 용기입니다. 온도·압력·수소가 올라갈수록 667의 개스킷이 먼저 한계에 닿고, 세정·증설·판 교체가 필요할수록 810의 고정 pack이 먼저 한계에 닿습니다.

실무에서 고르는 기준

667 semi-welded가 유리

한쪽만 위험 유체. 면적 증설(20%)이 필요. 판 pair 단위 교체. 설계압·온도가 P&F 개스킷 한계 안. 배관 하중이 작고 fixed cover 노즐로 처리 가능.

810 plate-block이 유리

양측 누설 불허 또는 탄성 개스킷 수명 부족. 고온·Cl.300 이상. H2/HTHS. Panel 개방 세정. 노즐 하중을 panel에서 받음 (Cl.600 표 있음).

제품 지도 — 같은 810 문법, 다른 용접 학교

현장에서 Compabloc / K°Bloc / GEABloc / LHEBloc이라고 부르는 기기는 모두 용접 plate pack + 4면 removable panel입니다. API 810이 이 형식을 코드로 받았습니다. 부품 이름과 하중 경로는 구조 페이지에서 분해합니다. 판 패턴·column liner·용접 방법·개스킷은 벤더가 다릅니다. 카탈로그 압력·온도는 모델·연도에 따라 바뀌므로 코드 한도가 아닙니다.

구조 — 810을 열어보면

습윤부

전열판 + comb/liner + baffle + (옵션) panel/nozzle liner. 보통 SS/합금/Ti. 탄소강 프레임에 공정이 닿지 않게 하는 것이 기본입니다.

프레임

column + top/bottom head + 4 panel. 탄소강 도장이 흔합니다. 노즐은 panel에 붙습니다. 패널 러그는 패널만 들어 올립니다. 본체 인양은 별도 러그.

유로

한 패스는 교차류, 배플로 패스를 쌓아 전체는 향류. 온도교차·응축·회수에 S&T 직렬보다 유리한 이유입니다. 배플이 꺾이면 바이패스 — 810이 청정 ΔP의 2배로 배플을 잡는 것과 같은 문제입니다.

판 패턴

Chevron(고 θ, ΔP 큼, 세정 쉬운 hydrojet). Double dimple / wide gap(저 θ, 고체·섬유, 양측 갭). LHE P&F는 L/H 두 골. 벤더가 “C-type plate”라고 하면 Compabloc 계열 골이지 667 개스킷 판이 아닙니다.

형식 선정 — S&T Rf를 판형에 넣지 말 것

컴팩트 HEX의 U가 높을수록 같은 fouling resistance가 % 과잉면적을 비정상적으로 키웁니다. Kelvion 예시: Uclean 2000인 S&T에 Rf 0.0001 m²K/W → 약 20% margin. Uclean 6000인 bloc에 같은 Rf → 약 60% margin. 유속이 떨어져 오히려 때립니다.

Fouling은 % margin + 벽면전단

Shell DEP 31.22.00.31(관형)도 Rf 표에서 % fouling margin으로 옮겼고, P&F DEP 31.21.01.32(2010)는 ISO 15547-1 위에 유체별 % + 최소 shear + 청정 ΔP + ΔP margin을 얹습니다. API 667/810 Annex와 같은 철학입니다. 발주처 DEP가 있으면 그 표가 우선입니다.

  • 허용 ΔP는 청정 기준. 펌프·배관 수력은 fouled ΔP.
  • 포트 ΔP는 전체의 20%를 넘지 말라는 owner 조항이 있습니다. P&F에서 포트를 작게 쓰면 여기서 깨집니다.
  • K°Bloc HTRI CTW 사례: 0.45 m/s에서도 벽면전단 ~60 Pa, S&T 1.8 m/s ~15 Pa. 유속만 비교하지 마십시오.
  • 왁싱은 margin 표 밖. 발주처와 별도 합의 (DEP 주석, Kelvion도 정지하 원유는 단기만 허용).

열계산에서 자주 엇갈리는 것

  • Bloc은 패스 단위 교차류입니다. HTRI/벤더 프로그램 없이 S&T F-factor만 넣으면 approach를 과대평가합니다.
  • NTU가 큰 회수는 향류 패스를 쌓습니다. Hisaka/LHE: 출구온도가 안 정해지면 NTU-ε, 정해지면 LMTD.
  • High θ (H, chevron 급) = 높은 U, 높은 ΔP. Low θ (L, dimple/wide) = 반대. 한 기기 안에서 thermal length를 맞춥니다.
  • LHE: 성형 깊이가 클수록 같은 ΔP에서 벽면전단이 커집니다. 810 dimple 5 mm 갭은 고체용이지 고θ가 아닙니다.

Owner 사양이 코드를 조이는 예 (Shell DEP 31.21.01.32)

  • 형식(개스킷/세미/완전용접)은 Principal이 고릅니다. 제작자에게 맡기지 않습니다.
  • Very toxic는 fully welded P&F. Rich amine/sulfinol은 세미용접 가능, rich는 용접 pair 안, 포트 개스킷은 TFE-P 계열.
  • Rich/lean solvent: 50% duty 프레임 2기 + 미설치 spare pack + 장래 spare 프레임 plot.
  • 각 스트림 입구 strainer. 추가 ΔP를 수력에 넣음.
  • 다단(multi-pass)은 Principal 승인 없이 금지.
  • 개스킷 판 최소 0.6 mm (667의 0.5 mm보다 큼). Tie bolt ≥19 mm. 노즐은 고정커버, 나사 금지, 최소 DN 40. ERW 노즐넥 금지.
  • 이것은 2010 ISO 15547-1 overlay입니다. 신규 P&F는 667 + 해당 발주처 DEP를 같이 읽으십시오.

설치·운전·세정 — IOM에서 실제로 깨지는 것

코드는 기기를 맞게 사고, IOM은 기기를 안 깨게 돌립니다. 아래는 Compabloc 영문 IOM, Kelvion K°Bloc 운전지침, Pertamina Balikpapan RDMP(IKAN) 개정, GEA Ecoflex 개스킷 P&F 매뉴얼의 공통항입니다.

배치

  • Panel 4면을 열 공간을 outline에 넣습니다. 밸브는 패널을 막지 않는 spool 뒤. 810 Scope(기계 세정)와 정면 충돌하는 지점입니다.
  • 패널 전용 인양 러그로 본체를 들지 않습니다. Compabloc IOM이 명시합니다.
  • 누설 시 오염이 문제면 containment / drip. P&F는 shroud·tray가 코드 옵션, bloc은 spray 전제가 다릅니다.
  • 패널 볼트 토크는 단열 전에, 그리고 수송·장기 보관 후에 다시. 2–3개월 정지 후 재기동 전에도.

두 IOM의 승온 한도는 다릅니다. 사양에는 “해당 제작사 IOM 또는 더 엄격한 쪽”을 쓰십시오. LHE가 column 용접 파손을 열팽창 문제로 보는 것과 같은 물리입니다.

세정

  • 화학세정(CIP)이 먼저입니다. 열지 않고 ΔP가 설정값에 닿으면 돌립니다. 미루면 유로가 막혀 회복이 안 됩니다.
  • 염산은 쓰지 않습니다 (Compabloc IOM). 세제·재질·때 양립은 제작사 확인.
  • 화학 후 철저히 수세·배수. 기계 세정은 패널을 열고 hydro-blast / cleaning bar를 약 45°로.
  • Chevron은 jetting에 유리, dimple/wide-gap은 고체용. 810은 기계 세정 스트림을 구매자가 지정합니다.
  • 원유 정체: Kelvion은 수시간 단기는 왁스·부식 모두 크게 보지 않음. 중장기 정지는 세정·플러시·배수.

개스킷 P&F (Ecoflex류) — bloc과 다른 실패

  • 개스킷은 소모품입니다. 설계 T/P를 넘기면 즉시 수명 종료. 접착식/클립식 혼재를 사양에 명시.
  • 기동 전 타이볼트·판 정렬 확인. 프레임 치수를 틀리면 누설 또는 판 변형.
  • Bloc의 panel gasket(흑연/PTFE/camprofile)과 P&F 탄성 개스킷을 같은 예비품 코드로 묶지 마십시오.

프로젝트에서 본 것

  • Pertamina RU V Balikpapan RDMP: Kelvion K°Bloc IOM을 프로젝트 개정으로 승온·ΔT·정체 원유 규칙을 못 박음 (IKAN, as-built 2022).
  • 국내 평가(P2-4PE, 2011): 용접 plate HEX 제작사가 적고, 본 제작·문서는 해외, 국내법만 로컬. 기술 질의 대응은 강점, 문서 경로는 단점.
  • 도면만 있는 패키지(DHP RPLC 등)는 운전 규칙을 주지 않습니다. IOM이 계약 문서인지 확인하십시오.

알아두면 좋은 것들

사양·발주

  • 장비 스케치를 보고 코드를 겁니다. Compabloc류에 667을 걸거나, 개스킷 P&F에 810을 걸면 Scope 위반입니다. 제품 지도 탭의 계보를 먼저 보십시오.
  • 662:2002는 예비품·기존 ITT 호환용입니다. 신규는 667 또는 810.
  • API는 압력용기 코드가 아닙니다. ASME VIII / EN 13445를 따로 지정하고, API는 그 위의 supplemental입니다.
  • 810 직렬 unit은 블록마다 설계온도·재질을 다르게 쓰지 않는 것이 기본입니다. 핫엔드만 Cr-Mo, 콜드엔드만 CS로 나누려면 구매자가 명시해야 합니다.
  • Fully welded P&F와 plate-in-shell은 코드 공백입니다. 압력코드 + 810의 용접/NDE + (프레임이면) 667을 선택 인용할지 사양에 쓰십시오.

열설계·운전

  • S&T fouling factor를 그대로 넣으면 과설계·저유속이 됩니다. % margin과 wall shear를 쓰십시오. 형식 선정 탭.
  • P&F는 포트 압력강하가 전체의 상당 부분을 먹습니다. 667은 포트 ΔP와 유속을 제안서에 넣으라고 합니다. Owner DEP는 포트 ΔP ≤ 20%를 자주 겁니다.
  • Chevron 각 정의가 vendor마다 다릅니다. 667/810은 “흐름 수직선 기준”입니다. HTRI/제작사 각도와 혼동하지 마십시오.
  • 입자 크기가 gap의 50%를 넘으면 strainer가 필요합니다 (662 Annex 권고, 이후 코드도 같은 취지).
  • 다단 667은 drain hole이 있어도 잔액이 남습니다. 유해 유체면 플러시 절차를 사양에 넣으십시오.

재료·손상기구

  • Loose liner는 sour 면제 티켓이 아닙니다. 810 Annex는 모재에도 sour 요구를 적용하라고 합니다.
  • HTHS에서 설계온도 ≠ 재료선정 온도일 수 있습니다. 금속 온도가 유체 설계온도보다 낮다고 주장하려면 계측·IOW가 필요합니다.
  • 810은 주강을 원칙 금지합니다. 노즐·커버에 주조품이 들어오면 막으십시오.
  • 판이 얇아서 부식여유를 못 줍니다. 재질을 한 단계 올리는 것이 CA 3 mm보다 맞습니다. LHE 예: 50 °C에서 합금에 따라 Cl⁻ 수십~수천 ppm, Ti 해수는 ~130 °C — 카탈로그이지 코드가 아닙니다.

인접 형식

  • PCHE는 청정·고압·근접온도용입니다. 더러운 유체에 넣으면 채널이 막히고 열 수 없습니다.
  • Brazed aluminium plate-fin은 극저온 다류. 현장 기계세정이 안 됩니다.
  • ACHX는 냉각수가 없을 때. 공정측 헤더 fouling이 크면 plug형 헤더를 검토합니다.

제작·검사에서 자주 빠지는 것

  • 810에서 수압 후 panel을 다시 열면 개스킷을 갈고 100–170 kPa soap 공압이 필수입니다. 현장 설치 후 재조립에도 해당될 수 있습니다. 기동 전 토크는 설치·운전 탭.
  • 세미용접 667의 용접 챔버는 수압 뒤 건조가 어렵습니다. 공압 대체를 사전에 합의하지 않으면 납기가 막힙니다.
  • 시험수 Cl⁻는 662가 30 ppm, 667/810은 50 ppm입니다. 구 사양을 그대로 복사하면 불일치입니다.
  • 수소 서비스에서 liner가 만든 밀폐 공간은 6 mm 벤트가 필요합니다. 빼면 운전 중 압력 축적·균열 위험이 있습니다.

배관·배치

  • P&F 가동커버 쪽 배관은 spool을 두어 커버를 빼게 하십시오. 고정커버에 노즐을 모으는 것이 667의 권고입니다.
  • 810은 panel 제거 공간을 outline에 넣습니다. 단열·플랫폼이 그 공간을 먹으면 기계 세정이 불가능해 Scope와 충돌합니다.
  • 컴팩트하다고 노즐을 짧게 쓰면 볼트를 못 뺍니다. 세 코드 모두 단열 너머 through-bolting 제거를 요구합니다.

Semi-welded의 용접 지위

  • 667 pair 용접은 일부 압력코드에서 압력유지 용접으로 보지 않을 수 있습니다. Annex는 그래도 코드 자격으로 시공하라고 합니다.
  • 810의 판 용접은 pack 누설 경로 자체이므로 압력코드 자격·NDE가 기본입니다. 같은 “판 용접”이어도 법적 지위가 다릅니다.

학습 노트이며 규격·카탈로그·IOM 원문을 대체하지 않습니다. 발주 전 API 662/667/810과 해당 제작사 IOM, 발주처 DEP를 확인하십시오. 벤더 압력·온도·면적은 모델 세대에 따라 바뀝니다.
