Study notes · not a substitute for the standards

W-PHEX

API 662 (2002), API 667 (2022), API 810 (2025 / Errata 1)을 welded plate heat exchanger 기준으로 읽고 정리한 노트입니다. 원문 검색·챗봇·API 키는 없습니다.

신규 용접형 plate-block은 API 810. 개스킷·세미용접 plate-and-frame은 API 667. API 662:2002는 세 형식을 한 권에 묶은 구판입니다.

한눈에

2002 · 통합 구판

API 662

2nd Ed., April 2002. ISO 15547:2000과 동일. 제목은 Plate Heat Exchangers for General Refinery Services.

Gasketed, semi-welded, fully welded plate pack을 프레임으로 구속하는 형식까지 한 문서에 담았습니다. Plate-block 구조는 정의하지 않습니다.

Sour/H2S, hydrogen, HTHS 전용 장이 거의 없습니다. 신규 발주에 그대로 걸기에는 빈 칸이 많습니다.

2022 · P&F 현행

API 667

1st Ed., March 2022. 구 API 662-1. 제목은 Plate-and-Frame Heat Exchangers.

Gasketed와 semi-welded P&F만 적용합니다. Fully welded P&F, welded plate-block, brazed plate, plate-in-shell은 명시 제외입니다.

세미용접 pair는 레이저 용접이 기본입니다. 판은 개별 또는 pair 단위로 교체하고, 프레임은 20% 추가 판 여유를 둡니다.

2025 · plate-block 현행

API 810

1st Ed., October 2025, Errata 1 July 2026. 제목은 Welded Plate-block Heat Exchangers.

용접 plate pack + 볼트 체결 removable panel. Compabloc / K°Bloc류가 여기에 해당합니다.

P&F(세미용접 포함)는 667로 보냅니다. 원통 shell 안의 block, panel로 기계 세정할 수 없는 구조도 제외입니다. HTHS는 Section 12와 API 941입니다.

용접형 PHE는 한 종류가 아닙니다

세 코드가 같은 “plate HX”를 다루지만, 용접 위치와 압력경계가 다릅니다. 발주 전에 장비 스케치로 형식을 확정한 뒤 코드를 걸어야 합니다.

API 662 · 667

Semi-welded plate-and-frame

인접 두 판을 pair로 용접하고, pair 사이는 개스킷으로 밀봉합니다. 한쪽 유체는 용접 챔버, 반대쪽은 개스킷 챔버입니다.

압력은 프레임·타이볼트·커버가 받습니다. 판 pair 단위로 교체할 수 있습니다. 한쪽만 공격적인 유체(암모니아 등)에 맞습니다.

API 662 only

Fully welded pack in a frame

개스킷을 전부 용접으로 대체한 plate pack을 프레임으로 구속합니다. 662 Scope에만 명시되어 있고, 667은 fully welded P&F를 제외합니다.

현재 전용 API가 없습니다. 662 인용은 레거시 해석용입니다.

API 810

Welded plate-block

전열판 pack을 용접하고, 모서리 column + 고정 head + 볼트 panel로 압력을 유지합니다. 유체 간 밀봉은 판 용접, 외부 누설 밀봉은 panel gasket입니다.

Panel을 열어 기계 세정합니다. 고온·고압, 양측 탄화수소, H2/HTHS에 맞습니다.

세 코드 제외

Plate-in-shell / block in shell

원통 shell 안의 welded plate-block, 또는 전 공정측을 panel로 기계 세정할 수 없는 구조입니다. 667·810 모두 명시 제외입니다.

Brazed plate, plate-fin은 별도 규격(구 662-2 / ISO 15547-2)입니다.

용어를 코드에 맞춰 읽기

  • 667의 plate-and-frame = gasketed 또는 semi-welded plate pack + supporting frame.
  • 810의 welded plate-block = 용접 plate pack + panels + fixed heads + columns.
  • 810의 plate pack = 전열판 + column liner + head liner의 용접 조립체.
  • 662의 fully welded plate pack = 개스킷을 용접으로 대체한 pack. 프레임은 그대로입니다.

Fouling

세 코드 모두 shell-and-tube의 fouling resistance를 쓰지 않고 % margin을 씁니다. 662 Annex는 최소 10%(crude 25%), wall shear ≥50 Pa를 권고합니다. 810 Table A.1은 유체별 margin·전단응력이 더 구체적이고, 양측 15%면 overall 25%를 권고합니다. 667도 같은 철학입니다.

판 용접이 갈리는 지점

Semi-welded P&F의 판 용접은 일부 압력코드에서 압력유지 용접으로 보지 않을 수 있습니다. Plate-block의 판 용접은 pack 누설 경로 자체이므로 810이 훨씬 촘촘합니다.

662 용접

압력용접은 압력설계코드, 구조용접은 구조용접코드입니다. 판 pair / fully welded pack 용접 절차·NDE는 구매자 임의입니다. Light box, PT, He leak는 지정할 때만입니다.

667 세미용접

Plate pair는 laser weld가 기본이고, 합의 시에만 예외입니다. 용접 후 개스킷 안착면 육안·스패터 제거. Vacuum / gas leak / eddy current는 구매자 지정입니다. Annex: 압력유지 용접 여부와 무관하게 코드 자격으로 시공합니다.

810 plate-block

전열판, pack–liner, liner–liner, panel/nozzle liner, 리프팅 러그 용접을 압력코드로 자격 부여합니다. Oxyacetylene 금지. Channel plug 수리는 사전 승인. H2 서비스는 밀폐 공간 벤트 홀이 필요합니다.

667 세미용접 vs 810 plate-block

667 semi-welded가 유리한 경우

한쪽만 위험 유체. 면적 증설(20%)이 필요. 판 pair 단위 교체. 설계압·온도가 P&F 개스킷 한계 안. 배관 하중이 작고 fixed cover 노즐로 처리 가능.

810 plate-block이 유리한 경우

양측 누설 불허 또는 탄성 개스킷 수명 부족. 고온·Class 300 이상. H2/HTHS. Panel 개방 세정. 노즐 하중을 panel에서 받음 (Class 600 표가 있음).

실무 공백

Fully welded plate-and-frame과 plate-in-shell은 세 문서 어디에도 현행 전용 요구가 없습니다. 해당 형식을 쓰면 압력설계코드에 더해, 판 용접·NDE는 810, 프레임이면 667을 선택 인용할지 구매 사양에 명시하는 것이 안전합니다.

이 페이지는 라이선스된 사본을 읽고 정리한 학습 노트입니다. 규격 원문을 대체하지 않습니다. 인용·수치는 발주 전에 API 662 2nd Ed. (2002), API 667 1st Ed. (2022), API 810 1st Ed. + Errata 1 (2025/2026) 원문으로 확인하십시오.
